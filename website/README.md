# Adhera website

React + TypeScript + Vite site for the Adhera smart pill organizer.

## Run locally

Install Node.js 20.19+ (or 22.12+), then in this folder run:

```sh
npm install
npm run dev
```

Open the Local URL printed by Vite. The address only works while `npm run dev` is running. To check a production build, run `npm run build`.

The organizer models are in `public/models/`, and the supplied logo is in `public/brand/`. Homepage copy is in `src/content.ts`.
